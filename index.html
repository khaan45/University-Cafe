Restore from Backup

This replaces everything currently on this device — every customer, invoice, bill, journal entry, and setting — with what's in the backup file. Anything entered since that backup was made will be lost. This can't be undone.

This permanently deletes data from this device/account's storage. It can't be undone. Logins (users) are never touched here — use Manage Users for that.
