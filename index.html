Import Multiple Invoices at Once
One row per invoice, each with a single line item — good for a backlog of existing debts. Columns: Customer Name (required — must match an existing customer exactly; add them under Customers first), Invoice Date (required), Due Date (optional), Description (optional, e.g. "Balance"), Amount (required), Tax (optional). Each row posts its own journal entry, same as creating one invoice by hand.
